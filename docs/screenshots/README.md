# Screenshots

Add your own screenshots or a short GIF here before publishing.

Suggested 20–30 second recording:

1. Right-click the tray icon.
2. Click **Disable system proxy**.
3. Show Windows Settings → Network & Internet → Proxy.
4. Click **Restore previous state**.
5. Show the proxy is back.

Suggested files:

```text
docs/screenshots/tray.png
docs/screenshots/demo.gif
```

Do not include real proxy credentials, internal hostnames, or personal account details in screenshots.
