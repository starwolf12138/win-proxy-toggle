# Changelog

## 0.1.0 — 2026-11-16

Initial portfolio release.

### Added

- PowerShell module for WinINET proxy state
- `status`, `disable`, `enable`, `restore` CLI actions
- saved state with `restore`
- `-DryRun`, `-Json`, `-IncludeAutoConfig`, `-SkipWinHttp`
- WinHTTP read and best-effort write
- tray icon with disable/enable/restore/exit
- single-instance tray mutex
- self-contained test suite using an isolated registry key
- case study and AI collaboration notes
- Chinese README and Chinese design notes
- Chinese comments in PowerShell files, saved as UTF-8 with BOM for Windows PowerShell 5.1
